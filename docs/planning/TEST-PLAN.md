## Affected Pages/Routes
- `/api/webhooks/stripe` — Stripe webhook handler (payment confirmation, session status transitions)
- `/api/cron/review-emails` — Vercel Cron endpoint (finds completed sessions, sends review emails)
- `/mentors` — Mentor listing with exact-match search (FROM/TO/country/price filters)
- `/mentors/[id]` — Mentor profile page (Cal.com embed, booking flow trigger)
- `/book/[sessionId]` — Stripe Checkout redirect + payment confirmation page
- `/reviews/[token]` — Post-session review form (rating, relevance, free text)
- `/auth/signin` — Magic link authentication (Resend)
- `/admin/mentors` — Founder verification dashboard (approve/reject mentors)

## Key Interactions to Verify
- Full booking flow: browse mentor → select Cal.com slot → Stripe Checkout → webhook confirms → email sent
- Mentor onboarding: magic link → profile form → LinkedIn URL → founder verifies → badge appears
- Search filtering: select FROM + TO → results update → empty state shows when no matches
- Review submission: click email link → rate session → submit → review appears on mentor profile
- Cancellation: cancel >24h (refund issued) vs. <24h (no refund, correct messaging)

## Edge Cases
- Payment abandonment: mentee selects slot, reaches Stripe, closes tab — slot must release
- Double-booking: two mentees select same slot simultaneously — only one should succeed
- Expired magic link: click after 24h — shows re-send option, not cryptic error
- Cal.com API down during webhook: payment succeeds but calendar confirmation fails — retry + alert
- Mentor with zero reviews: profile page shows "No reviews yet" gracefully
- Search with zero results: shows helpful empty state, not broken page
- Webhook replay/duplicate: same event ID processed twice — idempotent, no double-confirm

## Critical Paths
- Booking → Payment → Confirmation (E2E: must work end-to-end for launch)
- Webhook → Status transition → Review email trigger (chain of 3 systems)
- Stripe Connect onboarding → Mentor can receive payouts
- Cancellation → Refund → Session status update → Slot released on Cal.com
