Mobile Navigation

The navbar currently hides its links on mobile — only the logo, "Sign in", and "Get started" button show. How should users access Features / How it works / Pricing on mobile?

A

Keep it simple — no menu

Leave the nav as-is. The CTA section and footer already link to Pricing. Nav links aren't critical on a landing page — the page itself guides users down.

Pros

  • Zero complexity
  • No JS needed
  • Faster

Cons

  • No way to jump sections from nav on mobile
B

Hamburger menu (slide-down)

Add a ☰ icon on mobile. Clicking it reveals a dropdown with Features, How it works, Pricing, and Sign in links.

Pros

  • Standard pattern — users expect it
  • All links accessible

Cons

  • Needs client component + state
  • Extra UI to maintain
C

Compact bar — inline links, smaller

Show nav links on mobile too, but make them smaller text and reduce padding so they fit. Drop "How it works" label to just "How it works" shortened.

Pros

  • No extra state/JS
  • Links always visible

Cons

  • Gets tight on small phones
  • Nav + Sign in + button may overflow
